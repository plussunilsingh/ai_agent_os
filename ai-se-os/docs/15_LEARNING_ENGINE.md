# 15 Learning Engine

## Purpose

Turn validated work and failures into reusable project intelligence. `34_CONTINUOUS_EVOLUTION.md` defines the authoritative v3 promotion and supersession rules.

## Responsibilities

- extract durable facts from completed tasks
- create failure playbooks
- update conventions and project patterns
- measure which prompts, models, and validations work

## Inputs

- completed task records
- validation reports
- recovery reports
- telemetry events
- human feedback

## Outputs

- append-only learning records and proposed memory/DNA/projection updates
- updated project conventions
- model performance notes
- validation recommendations

## Internal Algorithms

1. Compare planned versus actual changed files and validation evidence.
2. Extract candidate summaries, decisions, and patterns with source provenance.
3. Detect repeated failures using material-sameness fingerprints.
4. Promote only validated facts/patterns or approved decisions.
5. Supersede or expire stale/contradicted memory without deleting lineage.

## Acceptance Criteria

- Successful tasks update memory only with validated facts.
- Failures become searchable playbooks.
- Learning records include provenance.
