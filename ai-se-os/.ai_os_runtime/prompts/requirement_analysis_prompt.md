# Requirement Analysis Prompt

Transform the user request into a structured requirement brief.

Include:

- user outcome
- scope
- non-scope
- assumptions
- unknowns
- affected modules
- risks
- complexity, confidence, token budget, and rollback impact
- acceptance criteria
- validation strategy

Do not propose implementation until ambiguity and impact are clear. Emit targeted questions or a Discovery task for unresolved high-risk uncertainty.
