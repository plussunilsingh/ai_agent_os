# Example SDLC Workflow

1. A user request creates a versioned requirement brief and audit event.
2. Requirement Completeness and Repository Intelligence produce impact evidence and a task-specific DNA slice.
3. Engineering Intelligence creates a bounded, versioned task DAG.
4. Scheduler grants a worktree-scoped lease and PDP grants task-scoped capabilities.
5. Context and Prompt Compilers produce reproducible, policy-bound artifacts.
6. Model Intelligence selects an eligible model, cost budget, and materially different fallback chain.
7. Execution applies only the leased task and emits an immutable execution record.
8. Validation maps each acceptance criterion to deterministic evidence and residual risk.
9. Recovery fingerprints failures and retries only with a material change; otherwise it escalates.
10. Learning promotes validated knowledge, refreshes affected projections/DNA, and records benchmark telemetry.
